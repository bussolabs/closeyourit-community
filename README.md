# CloseYourIt

**Errors, tickets and monitoring in one workspace.**

CloseYourIt connects errors, uptime, performance, logs and the work needed to fix problems.

## Open-source release in preparation

This is the public repository for the upcoming self-hosted distribution. The first source release and container image have not been published yet. This repository currently contains community and launch preparation documents; it is not an installable application.

Visit [closeyour.it](https://closeyour.it) for current availability. Installation instructions will be published alongside the first verified release.

## Contribute

Read [CONTRIBUTING.md](CONTRIBUTING.md), [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) and the existing [contributor agreement](CLA.md). You can report problems and propose improvements using the issue forms. Source changes can be proposed once the first source release is available.

For vulnerabilities, use [private vulnerability reporting](https://github.com/bussolabs/closeyourit-community/security/advisories/new), following [SECURITY.md](SECURITY.md).
